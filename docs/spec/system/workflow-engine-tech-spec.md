# Workflow Engine Specification

The former event-driven workflow engine and its product-specific process definitions have been removed from the boot application.

The canonical implementation is documented in [Custom Ecommerce Workflow Framework](workflow-framework-tech-spec.md). It provides the typed definition model, deterministic transition engine, durable persistence contracts, timers, retries, signals, compensation, cancellation, and runtime ports.

This file remains as a stable documentation link for older references. It does not describe an active implementation and must not be used to add new product workflow integrations.
